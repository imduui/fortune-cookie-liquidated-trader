One fortune-cookie line for a crypto trader who has just been liquidated —
an oracular fortune whose punchline lands on the loss itself, warm and
rueful rather than cruel. Entry for the
[Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c)
bounty on [make.fun](https://make.fun/r/4scqj2d7).

## The fortune

> Your lucky numbers are 0, 0, 0, and 0: liquidated at 3am, yet fortune insists your luck turns now.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a small deterministic Python program (no dependencies, no
network). It writes exactly one line of plain text to `/output/entry.txt`:
at most 20 words and 1–160 characters, as the bounty gate requires.
